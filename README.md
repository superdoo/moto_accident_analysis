# 🏍️ Texas Motorcycle Fatalities 2023 – Helmet Usage Analysis

This project analyzes motorcycle **fatalities in Texas during 2023**, with a particular focus on the impact of **helmet use**. It provides insights through automation, data visualization, and code quality enforcement.

## 📊 Features
- Extracts and analyzes 2023 Texas motorcycle fatality data
- Correlates helmet use with injury/fatality outcomes
- Generates dashboards using Flask (FastAPI planned)
- Automates tasks with Jenkins CI/CD pipelines
- Integrates SonarQube for static code and security analysis

## 🛠️ Tech Stack
- Python
- Flask (FastAPI planned)
- PostgreSQL / SQLite
- Jenkins
- SonarQube
- Docker
- GitHub
